# get_lab_test_catalog Tool

## When to use this tool

- When a patient asks about laboratory tests or diagnostic services
- When someone wants to know available tests at the clinic's lab
- When patients ask about test prices or costs in PKR
- When someone inquires about test availability or if a specific test is offered
- When patients want to compare test options

## What this tool does

- Retrieves the complete diagnostic lab test catalog from the database
- Returns test names with their descriptions
- Shows availability status for each test
- Provides price rates in Pakistani Rupees (PKR)
- Gets real-time updated test information from the backend

## What type of questions it can answer

- "What lab tests do you offer?"
- "How much does a blood test cost?"
- "Is the cholesterol test available?"
- "What are your test prices in PKR?"
- "Do you offer X-ray services?"
- "How much for a complete blood count (CBC)?"
- "What diagnostic tests are available?"
- "Can I get an MRI at your lab?"
- "What is the cost of a lipid profile test?"
- "Do you have pregnancy test available?"
- "Tell me about your lab testing services"
