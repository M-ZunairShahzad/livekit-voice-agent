
# get_doctors_info Tool

## When to use this tool

- When a patient asks about doctors or physicians at the clinic
- When someone wants to know doctor availability or consultation schedules
- When patients ask about doctor qualifications, specializations, or experience
- When patients want to know which doctors are active/available
- When someone asks for a list of all registered doctors

## What this tool does

- Fetches the complete list of registered doctors from the clinic database
- Returns each doctor's full name, qualifications, and medical specializations
- Shows active/inactive status of each doctor
- Provides weekly consultation schedules (day-wise availability)
- Retrieves real-time data from the backend server

## What type of questions it can answer

- "Who are the doctors at your clinic?"
- "What doctors are available today?"
- "Which doctors are specialized in cardiology?"
- "What are Dr. Zunair's qualifications?"
- "Is Dr. Khalid available on Friday?"
- "Can you tell me about your doctors?"
- "Which doctors are currently accepting patients?"
- "What are the consultation timings for Dr. Ali?"
- "Do you have a gynecologist available?"
- "Tell me about your senior doctors"
